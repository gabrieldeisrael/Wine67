Tutorial

1. Abra a pasta onde seu jogo (ou apenas o arquivo .sh) foi baixado.

2. Clique com o botão direito na pasta e escolha "Abrir no Terminal".

Copie e cole os comandos abaixo, tem uma versão para cada opção:

Para Wine67:

chmod +x wine67.sh && ./wine67.sh

Para Wine67 com CS 1.6:

chmod +x cswine67.sh && ./cswine67.sh

Após isso o processo deve ser bem intuitivo.
